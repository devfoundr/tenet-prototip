# TENET — прототип нового сайта

**Посмотреть:** https://devfoundr.github.io/tenet-prototip/

Прототип редизайна сайта студии TENET (Нижний Новгород) — лазерная эпиляция, массаж, аппаратная коррекция фигуры, уход за лицом.

## Задача

- Отдельные страницы под каждую услугу — для рекламы в Яндекс Директе
- Формы записи с передачей услуги и UTM-меток
- Удобная мобильная версия
- Перенос на WordPress после согласования

## Что есть в прототипе

- Главная и страница услуги «Массаж» (шаблон для остальных услуг)
- Адаптив: десктоп, планшет, телефон
- Меню-бургер и закреплённая панель записи на мобильном
- Форма записи с маской телефона (демо, заявки не отправляются)

## Статус

Черновик для согласования с клиентом. Цены, опыт мастеров и описание аппарата — предварительные, требуют подтверждения.
